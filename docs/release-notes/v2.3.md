## v1.0.0 → v2.3.0 主要新增

### 重复清理（新）
- **跨文件夹自动找完全相同的图**（SHA256 内容指纹），一键移到废纸篓省硬盘空间
- **批量 + 单组双入口**: 顶栏「移入废纸篓 (N)」批量删全部待删, 或行展开后底部「删除这组」/ 右键「立即删除此组」单组立删（不需要勾选先批量再删）
- **「逐组审阅」浮层**：所有 pending 组都可逐组眼审, ← → 切组、Enter 确认、Esc 关闭（不再被 ≥3 张副本门控）
- **撤销支持**：删错可一键还原（banner [撤销] 按钮，整批回原路径）
- **bookmark 权限升级引导**：V1 用户首次清理时引导重选根目录（macOS 沙盒模型限定 read-only bookmark 不能升级为读写）

### 跨文件夹找类似图（新）
- 用 Vision feature print 在选中图 ±5 张内找视觉相似（角度 / 滤镜 / 微调过的复制品）
- **⌘F 触发**，临时结果视图浏览

### 全局搜索（新）
- **⌘F 在全部受管文件夹搜文件名 / 路径**
- 类型 / 大小 / 时间三组筛选 chips，多维过滤

### 看图增强
- **旋转**: 左 L / 右 R
- **翻转**: 水平 H / 垂直 V
- **信息切换**: ⌘I 显 EXIF / 文件大小 / 像素尺寸 / 拍摄时间
- **复制**: 复制图 ⌘C / 复制路径 ⌘⌥C / 在 Finder 中显示 ⌘⇧R
- **删除到废纸篓**: Delete / ⌘⌫ + 撤销 toast（5s 内可还原）
- **右键 contextMenu 8 项** + bottomToolbar「更多 ⋯」镜像菜单（不右键也能发现）
- **全屏完美填满**: 当图片分辨率 ≥ 屏幕 + 宽高比一致时, 全屏自动去掉四周黑边完美填满; 不匹配时维持留呼吸边（避免上采样模糊或勉强裁切）

### 多种打开方式（新）
- **Finder「打开方式」选 Glance** — 看图窗独立，不打扰主窗
- **Dock 拖图标打开**（拖图到 Glance Dock 图标直接看）
- **关窗驻留**（像 Photos）—— 关掉看图窗 app 不退出，下次再打开秒开

### 菜单栏完整化
- 文件 / 编辑 / 显示 / 图像 / 窗口 五大菜单 16 项快捷键统一
- 之前部分快捷键缺顶部菜单入口（v1.0 限制），v2.3 补齐

### 智能文件夹（新）
- 「全部最近」/「本周新增」/「上个月」/「截图」/「大图」5 个内置
- 直接看跨文件夹的最新照片，不用一个一个文件夹翻

## 稳定性修复（用户可感知）

- **删图不再误关窗**：快速看图器删 1 张图不会意外关闭整个看图窗（v1.0 此处有 bug，根因是 SwiftUI Window scene 与 NSWindow 状态不同步，v2.3 改 AppDelegate 自建 NSWindow 解决）
- **全屏/toolbar 状态更稳**：快速看图器全屏切换状态机重写，4 态（普通窗口 / 原生全屏 / 继承主窗全屏 / 转场）清晰区分，不再卡死或误退
- **重复清理浮层** trashing 期间 disabled + 完成后队列重算，避免点击产生 race condition
- **方向键导航 crash 修复**：高频按 ← ↑ ↓ → 切图不再触发 Array 越界 crash（race: closure captured snapshot 跟 store 当下值不一致）
- **选文件夹默认高亮第一张**：进文件夹后第一张图自动高亮, 键盘 ← → 导航起点对齐用户预期
- **F 键全屏全场景生效**：重复清理总览 / 找相似图临时结果页面下 F 键也能切全屏（之前这两页 F 键无人接吞掉）
- **切换文件夹焦点不丢**：V1↔智能文件夹来回切, 方向键持续响应（之前 view swap 时焦点会丢）
- **侧边栏右键刷新**：右键任意节点点「刷新」会重建子文件夹树（捕获 Finder 里新建的子文件夹）, 不依赖 selection

## 数据安全 & 隐私

- ✅ App Sandbox 沙盒（用户授权才能读特定文件夹）
- ✅ Apple Developer ID 签名 + 公证 + .app standalone staple（Hardened Runtime）
- ✅ Security Scoped Bookmark — 重启后自动恢复授权
- ❌ **零网络请求 / 零数据上传 / 零遥测**
- ✅ **不永久删除**：「移到废纸篓」走 macOS 系统废纸篓，不直接 unlink；单图删除右下角 toast 提供 5s 撤销时间窗口
- ✅ **批量去重撤销**：重复清理后的 banner [撤销] 按钮能整批还原回原路径（只要废纸篓还在）

## 升级提示（v1.0.0 用户）

- 首次进「重复清理」会弹「升级清理权限」sheet，按提示**重选根文件夹一次**即可
- 原因：macOS 沙盒模型限定 — V1 时代的 read-only bookmark 不能升级为读写，必须重新创建一次。Sheet 内 DisclosureGroup 有完整技术解释。

## 已知 limitations

- **重复清理 ≥3 张副本组路径未真机验**（开发机当前 DB 只 2 组各 2 张，写自动化测试已覆盖，但真机肉眼未跑过）
- **外置 USB / iCloud Drive 行为未完整真机矩阵验**（M4 任务 2 前置门控部分覆盖，写 PENDING 跟踪）
- **万图大库（>10k）性能未验收**（M2 K.4 / M3 Slice M deferred）
- 不支持 RAW / HEIC / GIF 动画（同 v1.0，看图引擎未升级）
