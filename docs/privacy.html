1. 核心承诺

Glance(一眼)是一款 macOS 本地图片浏览与重复清理工具。我们的核心承诺非常简单:

  • 零网络请求 — App 启动后不发起任何 HTTP / HTTPS / TCP / UDP 连接, 你可在 macOS Activity Monitor → Network 实时验证
  • 零数据上传 — 任何元数据 / 索引 / 图像内容都不会上传到任何服务器, 包括我们自己也没有服务器
  • 零遥测 — 不收集崩溃报告 / 使用统计 / 设备标识 / 任何形式的分析数据
  • 零账号体系 — 不需要注册 / 登录 / 验证邮箱, App 装好即用

2. 本地索引数据明示

为了实现"跨文件夹查找重复图 / 找相似图 / 全局搜索"功能, Glance 在你的设备本地建立索引。所有索引数据存放在 macOS 应用沙盒容器内, 仅本机可访问:

~/Library/Containers/com.sunhongjun.glance/Data/Library/Application Support/

索引内容包括:

  • 缩略图缓存 — 加速图片网格滚动, 仅缓存你选择的文件夹内图片的小尺寸预览
  • SHA256 内容指纹 — 用于"重复清理"功能, 完全本地计算(macOS CryptoKit framework), 不外传
  • Vision 图像指纹(Feature Print) — 用于"找相似图"功能, 通过 Apple Vision framework 在设备上推理生成, 不联网
  • SQLite 索引数据库 — 记录文件夹结构 / 文件路径 / 拍摄时间 / EXIF 元数据等, 仅供 App 自身查询使用

这些数据全部存储在你的设备本地, 不上传任何服务器。卸载 App 后所有索引数据会被 macOS 自动清除。

3. 用户授权与文件访问

Glance 运行在 macOS 应用沙盒内, 这意味着:

  • App 无法访问任何文件, 除非你主动通过文件选择器或拖拽授权
  • 授权后, macOS 通过 Security Scoped Bookmark 机制持久化该权限, 仅本机有效
  • 你可以随时在系统设置或卸载 App 来撤销所有授权
  • App 不会自动扫描整个磁盘 / Documents / Pictures 等系统目录, 只看你主动添加的文件夹

4. 删除安全

Glance 的"重复清理"功能涉及移除文件, 我们采用最安全的方式:

  • 所有删除操作走 macOS 系统废纸篓(通过 FileManager.trashItem API)
  • 从不直接 unlink 文件 — 你永远可以从废纸篓恢复
  • 批量删除有撤销横幅, 单图删除有 toast 提示, 单图删除可在 5 秒内一键撤销
  • App 内不提供"永久删除"按钮, 删除决策权完全在 macOS 系统层

English Version

1. Core Promise

Glance is a macOS local image browsing and duplicate cleanup tool. Our core promise is simple:

  • Zero network requests — The app makes no HTTP / HTTPS / TCP / UDP connections. You can verify this in real time via macOS Activity Monitor → Network
  • Zero data upload — No metadata, index, or image content is uploaded to any server. We don't even have a server
  • Zero telemetry — No crash reports, usage statistics, device identifiers, or analytics of any kind
  • Zero accounts — No registration, login, or email verification. Install and use

2. Local Indexing Data Disclosure

To support cross-folder duplicate detection, similar image search, and global search, Glance builds an index locally on your device. All index data is stored inside the macOS application sandbox container, accessible only on the local machine:

~/Library/Containers/com.sunhongjun.glance/Data/Library/Application Support/

The index contains:

  • Thumbnail cache — Accelerates image grid scrolling. Caches small previews of images in folders you have selected
  • SHA256 content fingerprints — Used by the duplicate cleanup feature. Computed entirely on-device via macOS CryptoKit framework, never transmitted
  • Vision feature prints — Used by the similar image search feature. Generated on-device via the Apple Vision framework, never transmitted
  • SQLite index database — Stores folder structure, file paths, creation dates, EXIF metadata, etc., for app's internal queries

All this data stays on your device and is never uploaded to any server. Uninstalling the app removes all index data automatically (handled by macOS).

3. User Authorization and File Access

Glance runs inside the macOS app sandbox, which means:

  • The app cannot access any file unless you actively authorize it via a file picker or drag-and-drop
  • Once authorized, macOS persists permissions via Security Scoped Bookmarks. These permissions are local-only
  • You can revoke all permissions at any time via System Settings or by uninstalling the app
  • The app never scans your entire disk, Documents, or Pictures folder automatically. It only sees folders you have explicitly added

4. Deletion Safety

Glance's duplicate cleanup feature involves file removal, handled in the safest way possible:

  • All deletions go through the macOS Trash (via the FileManager.trashItem API)
  • We never directly unlink files — you can always recover from Trash
  • Batch deletions show an undo banner; single deletions show a toast with a one-click undo within 5 seconds
  • The app provides no "permanent delete" button. Final deletion authority rests entirely with the macOS system layer

6. Legal Framework Statement

Because Glance collects no user data, the following international privacy frameworks are all in a "not applicable / fully compliant" state:

  • GDPR (EU General Data Protection Regulation) — No collection = no need to declare legal basis, data processor, cross-border transfers, etc.
  • CCPA (California Consumer Privacy Act) — No collection = no data to "sell" or "share"
  • PIPL (China Personal Information Protection Law) — No collection = no personal information processing
  • COPPA (Children's Online Privacy Protection Act) — No collection = no age distinction needed, no child data involved

If you wish to "delete" your "data", the operation is trivial: uninstall the app, and macOS automatically clears the sandbox container with all local indexes.
