### Phase 4 — tag + GitHub Release (不可逆) — codex P1 顺序调整

**新顺序: 本地 tag → 全量 precheck → release create → 最后 push tag** (避免裸 tag 留远端)

军哥 final 拍板后, CC 跑:

```bash
# 1. 本地 tag(不 push)
git tag v2.3 -m "Glance 2.3.0 GA — 重复清理 + 看图增强 + 菜单栏"

# 2. 全量 precheck(codex P1, gh release create 不可 dry-run, 必须前置查)
[ -f "dist/Glance-2.3.0.dmg" ] || { echo "FAIL: DMG missing"; exit 1; }
[ -f "dist/Glance-2.3.0.dmg.sha256" ] || { echo "FAIL: sha256 missing"; exit 1; }
[ -f "docs/release-notes/v2.3.md" ] || { echo "FAIL: release notes missing"; exit 1; }

# 远端 tag 是否已存在(防 race / 残留)
git ls-remote --tags origin v2.3 | grep -q v2.3 && { echo "FAIL: tag v2.3 already on origin"; exit 1; }

# GitHub release 是否已存在(防之前部分跑过)
gh release view v2.3 2>/dev/null && { echo "FAIL: release v2.3 already exists"; exit 1; }

# Asset 大小 + SHA256 实测(release notes 数据真实性, codex P2)
ls -lh dist/Glance-2.3.0.dmg | awk '{print "DMG size:", $5}'
shasum -a 256 dist/Glance-2.3.0.dmg
cat dist/Glance-2.3.0.dmg.sha256
echo "PRECHECK PASS"

# 3. 创建 GitHub Release(不可逆但限于 GitHub 域)
gh release create v2.3 \
  dist/Glance-2.3.0.dmg \
  dist/Glance-2.3.0.dmg.sha256 \
  --title "Glance 2.3.0 · 一眼" \
  --notes-file docs/release-notes/v2.3.md

# 4. release 创建成功才 push tag(避免裸 tag 留远端)
git push origin v2.3
```

**风险**:
- `gh release create` 可删但 GitHub 会留 webhook / star feed 痕迹
- tag push 后可删但 `git tag -d v2.3 && git push --delete origin v2.3` 公开记录
- → ship 前**军哥明确 final go**, 不擅自跑

**FAIL 处理**:
- precheck 失败 → 修后重 Phase 4(本地 tag 可删除重建无副作用)
- `gh release create` 失败 → 本地 tag 还在但远端没污染, fix 后重跑
- `git push origin v2.3` 失败 → 远端 release 已发但 tag 在 release 自身的 commit 引用上, 用 `gh release edit` 修复
